#  Python To-Do List Manager

A simple and user-friendly console task manager written in Python. This project is designed for managing daily tasks with data persistence saved to a local file.

##  Features
- Add new tasks.
- View the list of all current tasks along with their completion status.
- Mark tasks as completed.
- Delete unnecessary tasks.
- Automatic data saving to the `tasks.json` file.

##  Technologies
- **Python 3**
- **JSON** (for data storage)
